# 🎭 وراء الكواليس | Malek

موقع تعليمي تفاعلي باللغة العربية مصمم ليأخذك في رحلة ساحرة لاستكشاف عالم المسرح وفنون التمثيل، من خلال تجربة فريدة تمنحك نظرة حقيقية على ما يحدث "وراء الكواليس".

## ✨ مميزات المشروع

يقدم الموقع محتوى تعليمياً وتفاعلياً يشمل عدة محاور أساسية:

*   **🎭 أساسيات الخشبة:** التعرف على عناصر المسرح وكيفية إدارة العرض.
*   **🎬 أسرار التمثيل:** دروس ونصائح حول فن الأداء والتحضير للأدوار.
*   **🎓 ماستر كلاس:** محتوى تعليمي متقدم لمحبي التعمق في الفن المسرحي.
*   **🪄 صناع السحر:** تسليط الضوء على الفرق الفنية (إخراج، سينوغرافيا، إضاءة) التي تصنع العرض.
*   **👶 ركن الأطفال:** محتوى مخصص لتبسيط مفاهيم المسرح للأطفال.
*   **😂 مواقف مسرحية:** قسم ترفيهي يستعرض طرائف المواقف التي تحدث على المسرح.

## 🚀 التقنيات المستخدمة

تم بناء المشروع باستخدام تقنيات الويب الأساسية لضمان السرعة والتوافق:
* **HTML5:** لبناء هيكل الموقع وتوفير تجربة محتوى غنية.
* **CSS3:** لتصميم واجهة عصرية وجذابة تتناسب مع الطابع الفني للمسرح.
* **Responsive Design:** الموقع متوافق تماماً مع جميع الشاشات (موبايل، تابلت، كمبيوتر).

## 🛠️ كيف تبدأ (التشغيل محلياً)

إذا كنت ترغب في تجربة المشروع على جهازك الخاص:

1. قم بتحميل المستودع (Repository) عبر الأمر التالي:
   ```bash
   git clone https://github.com/elsherbini00/malek.git
   ```
2. انتقل إلى مجلد المشروع:
   ```bash
   cd malek
   ```
3. افتح ملف `index.html` في أي متصفح ويب.
